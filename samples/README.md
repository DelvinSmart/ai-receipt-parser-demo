# Samples

Coloca aquí tickets de ejemplo (sintéticos o anonimizados — nunca una
foto real con datos personales) para probar `cli.py` localmente.

El `.gitignore` del proyecto excluye imágenes `.jpg`/`.png` en general,
pero permite explícitamente las que estén dentro de esta carpeta
(`samples/`), así que cualquier imagen de ejemplo que pongas aquí sí se
puede commitear si quieres incluirla en el repo.
